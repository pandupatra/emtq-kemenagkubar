# Tindak lanjut audit copywriting 001

Pengguna menyetujui semua temuan (1 sampai 11).

1. Nomor peserta diganti ID peserta; nilai ID tetap sama.
2. Status sesi tertutup menjadi Ditutup dan Sesi ditutup. Warna badge peringatan tetap dipertahankan.
3. Reset akses menjadi Reset kata sandi. Dialog menampilkan batas 12 sampai 128 karakter sesuai validasi. Pesan server diselaraskan.
4. Opsi pengulangan paket diperjelas, termasuk cakupan seluruh kecamatan dan penggunaan kembali paket dari hasil yang dibatalkan.
5. Instruksi Supabase, migrasi, dan AKUN.md pada aplikasi diganti petunjuk menghubungi pengelola aplikasi.
6. Label tabel akun menjadi Kecamatan dan Nama pengguna. Selector CSS untuk sel identitas diperluas ke Kecamatan agar perlakuan tipografinya tetap konsisten pada layar kecil.
7. Bukti, bank paket, dan header CSV menggunakan Ayat / rentang materi; header CSV juga menggunakan Surah / materi.
8. Konfirmasi akun menjelaskan akibat pengaktifan atau penonaktifan. Tombol menyebut Aktifkan akun atau Nonaktifkan akun.
9. Judul log menjadi Catatan aktivitas.
10. Slogan login menjadi Kelola peserta dan undian maqro.
11. Login hanya menyarankan koreksi kredensial untuk kode invalid_credentials. Kegagalan lain memakai pesan umum. Kegagalan pembaruan kata sandi dan catch route reset tidak lagi menebak penyebabnya.
